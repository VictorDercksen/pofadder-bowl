## Roles (enforced in RLS and RPCs, never client-side)

- **admin** · invites, roles, event participant, Sleeper import and link confirmation, event settings, prediction rules. Only Victor. Cannot remove own admin.
- **commissioner** · refereeing: review/approve/flag evidence, penalties, official results, resolve predictions, confirm bingo incidents, issue certificate. Admins inherit this.
- **participant** · Victor for this event: uploads, check-ins, press answers, certificate consent.
- **member** · everyone else: feed comments and reactions, bingo proposals, predictions.

The header badge lists every hat the account wears (Victor sees `ADMIN · PARTICIPANT`). Admins, commissioners and the participant get a **View as league member** switch (header, mobile drawer, and the orange banner while active). It sets the `pb-member-view` cookie; `getLeagueContext` then resolves the account as a plain member for every page and server action (`src/lib/roles.ts`, `src/lib/actions/view.ts`). The cookie only ever removes capabilities and RLS still knows the real role.

Members claim one NFL franchise at first sign-in (`/choose-team`); a franchise is unique per league (`claim_kit` RPC + unique index). The badge and kit colours follow the member across posts, review, bingo, predictions, press room and the mobile drawer.

## Authentication

- Sleeper has no OAuth; it is read-only. Auth is Supabase invite-only magic links. Sleeper managers are imported (league `1313900125680054272`) and linked to accounts by the admin.
- `/auth/confirm` accepts `token_hash` (custom templates), PKCE `?code=`, and implicit `#access_token` links (via `/auth/session`). Free-tier Supabase blocks custom email templates with the default mailer, so production uses default templates and the implicit path.
- **Blocker for inviting the league:** Supabase’s default mailer only delivers to the Supabase organisation’s own members. Configure custom SMTP (Resend/Postmark) under Project Settings → Auth → SMTP before inviting anyone else, or generate invite links with `admin.auth.admin.generateLink` and hand them over.
- Config gotcha: `[auth.email] enable_signup=false` disables the whole email provider (all logins). Invite-only is the top-level `[auth] enable_signup=false` only.

## Known quirks

- Regenerate types with `npx supabase gen types typescript --db-url postgresql://postgres:postgres@127.0.0.1:54322/postgres` and strip anything before `export type Json`; the `--local` form has hung on this machine.
- `.env.hosted` was once written with CRLF and the stray `\r` broke the league slug on Vercel. Values are clean now; keep env files LF.
- Vercel’s Node version comes from `engines.node` (`22.x || 24.x`) and `.node-version` (24).
- Playwright uses `@playwright/test` with Chromium installed via `npx playwright install chromium`.
